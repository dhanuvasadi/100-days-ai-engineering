# Day 10 - My First AI Python Program

## Objective

Learn how AI applications build prompts dynamically using Python.

---

## What I Learned

- Python variables store data.
- f-strings insert variables into text.
- AI applications build prompts dynamically.
- Context and user questions become part of the prompt.

---

## Code Summary

Today I created my first Prompt Builder using Python.

The program builds a prompt by combining:

- Role
- Context
- Question

This is similar to how enterprise AI assistants prepare requests before calling an LLM.

---

## Interview Takeaway

Prompt builders are responsible for combining user input, retrieved context, and system instructions before sending the request to an AI model.
